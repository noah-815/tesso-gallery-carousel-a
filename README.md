## 동작

| 항목 | 내용 |
|---|---|
| 전환 | 가로 슬라이드(translateX) 500ms. 이전 이미지가 왼쪽으로 밀려나가고 다음 이미지가 오른쪽에서 밀려들어옴 (시안 주석) |
| 루프 | 마지막 ↔ 처음도 같은 방향으로 이어서 슬라이드 |
| 자동 넘기기 | 데모 패널에서 on / off, 간격 2–5초 (기본 on · 3초) |
| 조작 | 스와이프/드래그, 인디케이터 클릭, 키보드 ← → |
| 인디케이터 | 최대 4개. 진행 방향에 이미지가 더 남아 있으면 활성 바가 끝이 아니라 끝에서 두 번째 칸에 머물고 줄이 한 칸씩 밀림. 끝에 도달하면 마지막 칸으로 |
